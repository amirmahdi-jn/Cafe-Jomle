# کافه‌جمله — نمونه اولیه رابط کاربری

این نسخه یک نمونه اولیه فرانت‌اند با HTML، CSS و JavaScript است.

## اجرا
فایل `index.html` را با مرورگر باز کنید. برای تجربه بهتر، اتصال اینترنت جهت بارگذاری فونت Vazirmatn لازم است.

## امکانات فعلی
- رابط فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ
- ناوبری بین خانه، برگزیده‌ها، روبورس، تازه‌ها، کاوش، اعلانات، پیام‌ها و پروفایل
- انتشار جمله جدید و افزودن هشتگ
- پسندیدن، ذخیره‌کردن و اشتراک‌گذاری متن
- جستجوی نمونه‌ای و تغییر پوسته روشن/تاریک
- نگهداری نمونه‌داده‌ها در localStorage مرورگر

## نکته مهم
این پروژه فعلاً فرانت‌اند نمایشی/تعامل‌پذیر است. ورود واقعی، ثبت‌نام، پیام‌رسانی زنده، مجوزها، پنل مدیریت واقعی و ذخیره‌سازی چندکاربره هنوز به بک‌اند و دیتابیس نیاز دارند. اطلاعات نمونه در مرورگر محلی ذخیره می‌شوند و بین کاربران یا دستگاه‌ها همگام نیستند.
